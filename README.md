# Backup Manager v5.2

## НАЗНАЧЕНИЕ:

Инкрементное резервное копирование в Telegram.

Backup Manager - это инструмент для автоматического резервного копирования файлов с поддержкой:
- Инкрементального бэкапа - копируются только измененные файлы
- Полного бэкапа - копирование всех файлов
- Смешанного режима - автоматическое переключение между типами
- Отправки в Telegram - архивы отправляются в Telegram канал
- Локального хранения - сохранение архивов на диск
- AES-256 шифрования - защита архивов паролем
- Восстановления - из полных и инкрементальных архивов



---
## УСТАНОВКА
---

1. Скачайте файл backup_manager.exe
2. Поместите его в любую папку на вашем компьютере
3. При первом запуске программа автоматически создаст файл конфигурации

Требования: Windows 7, 8, 10, 11 (64-bit)

## НАСТРОЙКА КОНФИГУРАЦИИ
---

### Автоматическое создание конфига

При первом запуске программа создаст файл `backup_config.ini` в той же папке,
где находится `backup_manager.exe`

  `backup_manager.exe backup`

### Структура конфигурационного файла

```cmd
[directories]
# Папки для бэкапа (через запятую)
# (recursive) - включая подпапки
# (non-recursive) - только файлы в папке
folders = C:\Users\USER\Documents (recursive), D:\Photos (non-recursive)

# Отдельные файлы или маски (через запятую)
files = C:\config.ini, *.pdf, *.docx

[exclusions]
# Исключаемые расширения
extensions = .tmp, .log, .cache, .thumb

# Исключаемые папки
folders = temp, __pycache__, node_modules, .git, .venv

[telegram]
# Токен бота Telegram (получить у @BotFather)
api_token = bot1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID канала (или username с @)
channel_id = @my_backup_channel

# Пароль для архива (оставьте пустым для архива без пароля)
password = MyStrongPassword123

# Максимальный размер файла для Telegram (МБ)
max_file_size_mb = 49

[backup]
# Файл для хранения контрольных сумм
storage_file = checksums.json

# Временная папка для создания архивов
temp_folder = temp_backup

# Только сканирование при первом запуске (true/false)
first_run_only_scan = true

# Файл логов
log_file = backup.log

# Папка для хранения архивов (локально)
archive_storage_folder = backup_archives

# Сколько последних архивов хранить
keep_last_archives = 10

# Тип бэкапа: full, incremental, mixed
backup_type = mixed

# Через сколько дней делать полный бэкап (для mixed)
full_backup_interval_days = 7

# Максимальное количество инкрементальных бэкапов
max_incremental_backups = 30
```

### Описание параметров

Параметр                        | Описание                          | Значение по умолчанию
--------------------------------|-----------------------------------|---------------------
[directories]                   |                                   |
folders                         | Папки для бэкапа                  | Пусто
files                           | Отдельные файлы или маски         | Пусто
[exclusions]                    |                                   |
extensions                      | Расширения файлов для исключения  | .tmp, .log, .cache
folders                         | Имена папок для исключения        | temp, __pycache__
[telegram]                      |                                   |
api_token                       | Токен Telegram бота               | Пусто
channel_id                      | ID или username канала            | Пусто
password                        | Пароль для архива                 | Пусто (без пароля)
max_file_size_mb                | Макс. размер части для Telegram   | 49
[backup]                        |                                   |
storage_file                    | Файл контрольных сумм             | checksums.json
temp_folder                     | Временная папка                   | temp_backup
first_run_only_scan             | Только сканирование при первом    | true
log_file                        | Файл логов                        | backup.log
archive_storage_folder          | Папка для архивов (локально)      | Пусто (в temp)
keep_last_archives              | Хранить последних архивов         | 10
backup_type                     | Тип бэкапа                        | mixed
full_backup_interval_days       | Интервал полных бэкапов (дни)     | 7
max_incremental_backups         | Макс. инкрементальных             | 30

### Типы бэкапа

Тип           | Описание
--------------|--------------------------------------------------------
full          | Всегда создается полный архив всех файлов
incremental   | Всегда создается инкрементальный архив (только изменения)
mixed         | Полный архив по расписанию, остальное инкрементальные

```cmd
Пример вывода:

  Полные архивы (2):
    * full_backup_20260121_143022.zip (125.34 MB, 2026-01-21 14:30:22)
    * full_backup_20260114_091503.zip (118.21 MB, 2026-01-14 09:15:03)

  Инкрементальные архивы (5):
    * inc_backup_20260121_223015.zip (2.34 MB, 2026-01-21 22:30:15)
    * inc_backup_20260120_183045.zip (1.89 MB, 2026-01-20 18:30:45)
    ...

  Для восстановления потребуется:
    * Полный архив: full_backup_20260121_143022.zip
    * Инкрементальных архивов: 3
```

### Восстановление файлов

```cmd

  # Базовое восстановление
  backup_manager.exe restore ./backup_archives

  # Восстановление в указанную папку
  backup_manager.exe restore ./backup_archives -o D:\restored_files

  # Восстановление с паролем (если архив защищен)
  backup_manager.exe restore ./backup_archives -p MyPassword123
```

### Параметры команды restore

Параметр               | Описание
-----------------------|----------------------------------------------------
archive_folder         | Папка с архивами (обязательный)
-o, --output           | Папка для восстановления (по умолчанию: ./restored_files)
-p, --password         | Пароль для архивов

Важно: При восстановлении программа автоматически найдет последний полный архив
и все инкрементальные архивы после него, и восстановит их в правильном порядке.

## ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
---

### Как получить токен бота Telegram?

  1. Напишите @BotFather в Telegram
  2. Отправьте команду /newbot
  3. Придумайте имя и username бота
  4. Получите токен вида bot1234567890:ABCdef...

### Как создать канал для бэкапов?

  1. Создайте новый канал в Telegram
  2. Добавьте своего бота в канал как администратора
  3. Используйте username канала (например @my_backup) или его ID

### Что делать при ошибке "Telegram отключен"?

```cmd
  Проверьте в конфиге:
    - api_token - не пустой и правильный
    - channel_id - указан правильно (с @ или -100...)
```

### Как восстановить файлы из инкрементальных архивов?

  Программа сделает это автоматически. Вам нужно указать только папку с архивами,
  она сама найдет последний полный архив и все инкрементальные после него.

### Безопасно ли хранить пароль в конфиге?

  Пароль хранится в открытом виде в конфигурационном файле. Рекомендации:
    - Ограничьте доступ к конфигу
    - Используйте права доступа к файлу
    - Храните конфиг в защищенном месте
    - В логах пароль скрывается автоматически

### Почему архив не отправляется в Telegram?

  Возможные причины:
    - Превышен лимит Telegram (макс. 50 МБ на файл)
    - Неправильный токен или ID канала
    - Бот не является администратором канала
    - Проблемы с интернет-соединением

### Что значит "Безопасный режим: ВКЛЮЧЕН"?

  Это означает, что все чувствительные данные (токены, пароли) автоматически
  скрываются в логах. Вы можете безопасно отправлять логи для диагностики.

### Как часто делать полный бэкап?

  Рекомендации:
    - Для активных данных: каждые 7 дней
    - Для архивных данных: каждые 30 дней
    - Для критических данных: каждый день

  Настройте full_backup_interval_days в соответствии с вашими потребностями.

## УСТРАНЕНИЕ НЕПОЛАДОК
---
```cmd
Ошибка: "Конфигурационный файл не найден"

  Решение: Создайте файл backup_config.ini в папке с программой или укажите путь
  через -c

Ошибка: "Не найдена ни одна библиотека для создания архивов"

  Решение: Переустановите программу или обратитесь в поддержку

Ошибка: "Недостаточно места на диске"

  Решение: Освободите место на диске или укажите другую временную папку
  с достаточным объемом

Ошибка: "Неверный пароль для архива"

  Решение: Проверьте пароль в конфиге или при восстановлении

Ошибка: "Telegram ошибка: 400 Bad Request"

  Решение: Проверьте правильность channel_id. Для каналов используйте формат
  @username или числовой ID с -100

Программа зависает на больших файлах

  Решение: Увеличьте max_file_size_mb в конфиге или исключите очень большие файлы

Логи слишком большие

  Решение: Удалите старые логи вручную или настройте ротацию логов через log_file

Ошибка при восстановлении: "File not found"

  Решение: Убедитесь, что указаны все архивы (полные + инкрементальные).
  Инкрементальные архивы без соответствующего полного не могут быть восстановлены.
```
